\## Architecture



Deterministic calculations are performed by code.



AI is used for:

\- planning

\- diagnosis

\- exception handling

\- quality review

\- economic interpretation



Research methodology is defined in configuration and should not be silently changed by an AI agent.



\## Reproducibility principles



\- Raw data are not overwritten.

\- Data transformations should be reproducible.

\- Validation must pass before statistical analysis.

\- Execution decisions should be logged.

\- Human intervention is reserved for substantive methodological ambiguity.



\## Computing environments



The repository may be cloned on:



\- Windows desktop

\- Windows laptop

\- Linux research server



GitHub serves as the canonical version-control layer across machines.
